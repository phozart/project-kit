When the user invokes this command, create or update the project chronicle (decision log).

## Steps
1. Read existing docs/chronicles/ entries
2. If no args: display chronicle summary
3. If "add": prompt for decision/event description, context, rationale
4. Create timestamped chronicle entry

## Usage
- `/chronicle` - View chronicle summary
- `/chronicle add` - Create new chronicle entry

$ARGUMENTS Optional "add" keyword to create new entry
